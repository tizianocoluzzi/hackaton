# Hackaton repository
## How to do things
- **creare ambiente virtuale con venv:**
``` bash
python3 -m venv .venv #crea ambiente virtuale nell cartella .venv
```
- **attivazione ambiente virtuale:**
``` bash
source .venv/bin/activate
```
- **installazione tramite requirements:**
```bash 
pip install -r requirements.txt
```
